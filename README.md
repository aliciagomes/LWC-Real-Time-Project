# LWC-Real-Time-Project

## Project Title

**Organization's Accounts and Contacts Management**

## Overview

This project aims to build a user-friendly interface for managing Accounts and Contacts in Salesforce. The application leverages Lightning Web Components (LWC) to provide an interactive, responsive, and efficient user experience.

The solution demonstrates component communication patterns, Salesforce data management, and modern UI development using the Lightning Platform.

---

## Project Components

### Parent Component

Acts as the main container and orchestrates communication between child components.

### Child Component One

Provides a search interface that allows users to filter contacts dynamically.

### Child Component Two

Displays the results returned from the search query and updates in real time based on user interactions.

### Additional Features

* Add new contacts
* Edit existing contacts
* Delete contacts
* View contact details

---

## Key Functionalities

### Search Functionality

Users can search for contacts using the search bar. Results are filtered and displayed dynamically.

### CRUD Operations

The application supports full contact management:

* Create Contacts
* Read Contact Information
* Update Existing Contacts
* Delete Contacts

### Responsive Layout

Built using Salesforce Lightning Design System (SLDS), Lightning Layout, and Lightning Layout Item components to ensure a clean and responsive user interface.

### Component Communication

Demonstrates communication between Lightning Web Components through parent-child interaction and event-driven architecture.
